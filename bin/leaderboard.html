How points work

Points depend on the kind of action, never on its size. Comments score at most once per thread per day (10 a day), replies on your own PR at most twice per PR, one review per reviewer per PR per day. Breaking main is the first red CI or Full Suite run after a green one, or, while main is already red, a run that fails a test that wasn't already failing; runner failures (disk, memory, timeouts) and failures that pass on re-run don't count. Each person takes only their largest penalty per break. The maintainer is scored but can't win; bots aren't ranked.
